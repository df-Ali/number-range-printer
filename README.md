# Number Range Printer

A simple C++ program that takes two numbers from the user and prints all the numbers between them.

## How it works
The program asks the user to enter two integers, then prints every number that lies between them.

## How to run
```bash
g++ main.cpp -o print_range
./print_range
```
Or open `print_range.cbp` in Code::Blocks and run it directly.

## Example
```
Enter first number: 3
Enter second number: 8
Numbers between: 4 5 6 7
```
